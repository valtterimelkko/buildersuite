# Master Concept Examples

This directory contains complete, realistic Master Concept document examples to illustrate best practices.

## Examples

### dashsync-example.md
A complete Master Concept for a fictional SaaS product "DashSync" - an automated metrics dashboard for early-stage founders. This example demonstrates:
- Well-defined problem statement with root cause analysis
- Specific, behavioral persona definition
- Clear Jobs to Be Done articulation
- Comprehensive MoSCoW prioritization
- Quantified success metrics with a North Star metric
- Identified riskiest assumption with validation plan

### How to Use These Examples

1. **Learning**: Read through to understand what a complete Master Concept looks like
2. **Validation**: Compare your concept document against these examples
3. **Structure**: Use as a reference for section depth and detail level

**Note**: These are fictional products created for educational purposes. Your Master Concept should be tailored to your specific product and market.

## Creating Your Own

To generate a template for your product:
```bash
.shared/scripts/master-concept/validate-concept.sh --generate-template docs/concept/your-product.md
```

To validate your completed concept:
```bash
.shared/scripts/master-concept/validate-concept.sh docs/concept/your-product.md
```
